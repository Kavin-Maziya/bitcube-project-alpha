## What was delivered
- User Story#1: A feature that allows employees to successfully book conference rooms and the system sends a notification after successful booking has been made

## What did not complete (And Why)

- User Story#4 Room booking Cancellation: Feature was not successful because the system was refusing to execute room cancellation due to existing recurring bookings and the system was crashing because of it, the feature's complexity is high and it needs to be broken down into small bits, the feature has been moved to the next Sprint because of it's complexity and business value
