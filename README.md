# Bitcube Project Alpha

This is assignment 1.3 CI Workflow automation 

The CI automation file runs atomatiocally when there's a pushed code to the directory and also when there's a pull request. Then it sets up what jobs and steps to run in the workflow. The first step checks the repository using actions version 3, the the second step runs the demo command. After it's done on the github repository it performs a cleaning task. 


Automation helps software engineers detect problems early, improves consistency, and saves time by reducing manual checking of code. CI also verifies code and gives feedback before merging any code to the main code.
