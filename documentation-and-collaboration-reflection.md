# Documentation & Collaboration Reflection

The original README assumed that contributors already understood the project structure, sprint workflow, and repository purpose. It  didn't provide any onboarding guidance and explanations for project artefacts, contribution workflows, and repository structure.

The updated README improves onboarding by clearly explaining the purpose of the Conference Room Booking System, repository structure, sprint artefacts, and upcoming sections. It now provides new contributors with a better understanding of how the repository is organised and how team members are expected to contribute through branches and Pull Requests.

Through this assignment, I learned that Pull Requests can also for communicating with conributors, explaining project context, and expectations to reviewers. Writing clear Pull Request descriptions helps reviewers understand why changes were made and what areas require attention.
